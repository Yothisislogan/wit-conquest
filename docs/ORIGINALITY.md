# Originality and provenance

Monster Territory is an original implementation. This document records where
every part of it came from, so the claim can be checked rather than taken on
trust.

## Summary

| Asset                | Source                                                            |
| -------------------- | ----------------------------------------------------------------- |
| Game code            | Written for this repository, from scratch                         |
| Board layouts        | Designed for this repository, generated from code                 |
| Character artwork    | Drawn as SVG paths in `src/ui/monsters.ts`                        |
| Board and UI artwork | CSS and SVG in this repository                                    |
| App icons            | Rasterised from code by `scripts/generate-icons.mjs`              |
| Sound effects        | Synthesised at runtime by the Web Audio API                       |
| Music                | Generated at runtime by the Web Audio API                         |
| Fonts                | System font stack only — no font files are bundled or downloaded  |
| Third-party runtime deps | None                                                          |

## What was deliberately not used

The game belongs to a well-established genre of turn-based territory-conversion
games. The *concept* — grow by cloning, travel by jumping, convert adjacent
opponents — is a game mechanic and is used freely. Nothing else was taken. In
particular this project does not contain, and was not derived from:

- source code, decompiled or otherwise, from any existing implementation;
- artwork, sprites, screenshots, textures or animation from any existing game;
- sound effects, music or audio samples from any existing game;
- board layouts copied from any existing game;
- names, logos, wordmarks or menu designs from any existing game;
- ROM images or extracted asset bundles of any kind.

The working title is "Monster Territory". It is not "Conquest", and the shipped
strings, icon and characters share no name, mark or likeness with any existing
product.

## Artwork

There are no image files in this repository except the generated PWA icons.

**Characters** (`src/ui/monsters.ts`). Two teams, each built from a handful of
SVG primitives in a 2×2 unit box:

- *Blobs* — a closed cubic outline with a weighted base, two eyes, a small smile,
  and a slow breathing idle.
- *Spikes* — a seven-pointed polygon generated by `spikePoints()`, one large eye,
  an angled brow and a jagged mouth, with a restless idle.

They are distinguished by silhouette first and colour second, which is both a
design choice and an accessibility requirement.

**Board and interface.** Hexes are polygons generated by `hexPolygonPoints()`
from the same maths the rules engine uses; every other surface is CSS. The colour
palette (deep indigo ground, violet accent, cyan and orange teams) was chosen for
this project, with the team pair selected for colour-vision robustness.

**Icons** (`scripts/generate-icons.mjs`). A dependency-free Node script that
renders a rounded hexagon with a gradient and an original one-eyed monster into
raw RGBA pixels with 4×4 supersampling, then encodes PNG files by hand
(IHDR/IDAT/IEND with correct CRC32) using `node:zlib`. It verifies its own output
by decoding it again. Regenerate with `node scripts/generate-icons.mjs`; the
result is deterministic.

## Sound

Every cue in `src/ui/sound-controller.ts` is generated at runtime from
oscillators, gain envelopes, biquad filters and an algorithmically produced noise
buffer. There are no audio files, no data-URI blobs and no sampled material. The
noise texture comes from a seeded LCG rather than `Math.random`, so the output is
identical on every device.

Cues: select, deselect, clone, jump, convert (scaled by how many monsters
flipped), turn change, win, lose, tie, invalid action, UI tap.

The soundtrack in `src/ui/music-controller.ts` is generated the same way. There
is no recorded, sequenced or licensed music anywhere in the project: a fixed
scale and chord table written for this game is walked by a seeded deterministic
generator, and each note is rendered by oscillators and envelopes through the
same audio graph as the effects. Nothing was transcribed from an existing piece.

## Board layouts

All three layouts are original designs, declared in `src/data/boards.ts` and
compiled at load time. Each is a regular hexagon of radius 4 (61 spaces) with an
obstacle set authored through `symmetricPairs()`, which adds the 180° rotation of
every coordinate — so rotational symmetry, and therefore side balance, is a
property of the construction rather than of review.

| Layout     | Playable spaces | Character                                    |
| ---------- | --------------: | -------------------------------------------- |
| Classic    |              55 | Open ground, six standing stones             |
| Crossroads |              48 | Blocked hub with spokes, six approach lanes  |
| Islands    |              51 | Three bands joined by narrow corridors       |

`validateBoard()` enforces the rules that make a layout shippable — full
rotational symmetry including obstacles, 45–65 playable spaces, mirrored starting
positions, every playable space reachable, and a legal opening move for both
sides. The unit suite runs it against all three layouts and additionally asserts
that both players start with an identical number of legal moves and identical
reach.

## Rules engine

The hex maths uses the standard public axial/cube coordinate system for hex grids
(neighbour offsets, ring construction, the `(|dq| + |dq+dr| + |dr|) / 2` distance
metric, and the axial↔offset conversions). That is common mathematical knowledge,
comparable to using Cartesian coordinates; the implementation in `src/game/hex.ts`
was written for this project.

## Dependencies

`package.json` has no runtime dependencies. The development dependencies are
Vite, TypeScript, Vitest, Playwright, jsdom and `@types/node` — build and test
tooling only. Nothing from them ships in the bundle beyond compiled project code.

## Reproducing this claim

```bash
# No bundled binary assets other than the generated icons.
find . -path ./node_modules -prune -o -type f \
     \( -name '*.png' -o -name '*.jpg' -o -name '*.webp' -o -name '*.mp3' \
        -o -name '*.ogg' -o -name '*.wav' -o -name '*.ttf' -o -name '*.woff*' \) -print

# The icons are reproducible from source.
node scripts/generate-icons.mjs && git diff --stat public/icons

# No runtime dependencies.
node -e "console.log(require('./package.json').dependencies ?? 'none')"
```
